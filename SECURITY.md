# Security Policy

If you discover a security vulnerability in JWTBlaze, please follow these
instructions so we can investigate and fix the issue as quickly as possible.

Reporting a vulnerability

- Email: `security@github.com` (or open a private issue if you have access).
- Include a clear description, reproduction steps, and any PoC code.

Responsible testing

This tool is intended only for authorized security testing. Do not use it on
systems you do not own or do not have explicit written permission to test. By
using JWTBlaze you agree to follow applicable laws. The project maintainers are
not responsible for misuse.

Disclosure timeline

We will acknowledge reports and coordinate privately. Once a fix is ready, we
will follow responsible disclosure practices.
